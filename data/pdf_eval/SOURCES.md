# Evaluation set: sources and licences

10 PDFs and 68 questions (`eval_dataset.jsonl`), small enough to evaluate the whole chain in a few minutes of
parsing. No Open RAG Bench content: its CC BY-NC licence forbids it in a commercial kit.

## Synthetic documents (8)

Generated by `scripts/make_eval_pdfs.py` (01 to 03 by `scripts/make_control_pdfs.py`, identical to `data/pdf_control`).
Fictitious organisations, places and figures; no licence restriction. `expected.json` gives their real headings.

## Known weak points the set measures

* q50 (08), like q23 (03): a code block is cut into short lines, each dropped as too short; the command is not indexed.
* q08, q13, q16, q28: values readable only on a chart, answered through the description of the vision model.
